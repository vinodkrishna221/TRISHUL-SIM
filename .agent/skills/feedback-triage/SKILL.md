# Feedback Triage

Purpose: external feedback under time pressure either gets lost, or worse — silently
inflates scope. This ritual makes it traceable and cheap. Run within 15 minutes of the
touchpoint, while verbatim. Owner: Intel seat / Scout (log), Orion (verdicts), human (calls).

## Step 1 — Capture verbatim (2 min)

In `board/EVAL-PACK-<round>.md` feedback table: WHO said it (judge #2, mentor A) ·
QUOTE (their words, not your summary) · what they were looking at when they said it.
Their phrasing carries scoring intent — "how will villagers with feature phones use this"
is a rubric line, not small talk.

## Step 2 — Classify (5 min, Orion chairs)

| Verdict | Criteria | Action |
|---|---|---|
| **ADOPT-NOW** | cheap (≤2h) AND judge-visible next round | card on a mission immediately, ⭐ if it's a scoring callback |
| **ADOPT-IF-TIME** | right but expensive | cut-list with rank; honest "on the roadmap" line scripted |
| **DEFEND** | we disagree with evidence | evidence gathered by Intel seat; delivered as callback NEXT round, never argued live |
| **DECLINE** | scope inflation / wrong for the demo | polite script: "we chose X so that Y — happy to discuss after"; logged so the team stops relitigating |

Mentor suggestions get the SAME table — mentors inflate scope with love; the cut-list
math (what would this displace?) is said out loud before any ADOPT.

## Step 3 — Trace (5 min)

- Direction-changers → 3-line DECISIONS entry (this doubles as viva material: "we
  considered X after round 1 feedback, chose Y because Z" is a winning viva answer).
- ADOPT-NOW cards created with timebox + owner; STATUS updated.
- **Callback script for next round** (the point of it all): "You asked about <X> — <here
  it is on screen / here's the number / we evaluated it and chose Y because Z>."
  Feedback visibly incorporated is among the highest-scoring behaviors in multi-round
  judging; feedback visibly ignored is among the most penalized.

## Step 4 — Close the loop

Next /eval-round's pack lists every prior item + status. Nothing external ever lands
directly in code or missions without passing this table — that's the scope-guard's
perimeter against the classic mid-hackathon feedback spiral.
