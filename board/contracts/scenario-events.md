# Contract: scenario-events
> version: 1 · 2026-10-04
> OWNER: unity-sim (produces events)
> CONSUMERS: swarm-ai (reads SCENARIO_START to seed swarm) · aar-engine (reads TICK + END to log + score) · ui-ux (reads all three to drive scene state + threat indicator)

All messages use the WebSocket IPC envelope from `websocket-ipc.md`.
Direction for all events in this file: **Server (Instructor C2) → Client (Trainee Cockpit)**.
The `SCENARIO_TICK` is broadcast at 10 Hz (every 100 ms); ticks are the clock of the simulation.

---

## SCENARIO_START

Fired once per run by the Instructor pressing "Launch Scenario".
The Trainee Cockpit must ACK within 1 s or the server logs a warning.

```
SCENARIO_START payload {
  sessionId:    string         // "sess-20261004-143201" — UUIDv4-like, generated by server
  scenarioId:   string         // matches ScenarioConfig.id, e.g. "punjab-fog-pincer-01"
  seed:         number         // RNG seed for this run (procedural variation)
  startedAtMs:  number         // server Unix ms — used as t=0 baseline
  scenarioConfig: ScenarioConfig  // full config (see SCHEMA.md Entity 1)
}
```

**Example:**
```json
{
  "type": "SCENARIO_START",
  "v": 1,
  "ts": 1759600021000,
  "payload": {
    "sessionId": "sess-20261004-143201",
    "scenarioId": "punjab-fog-pincer-01",
    "seed": 42819,
    "startedAtMs": 1759600021000,
    "scenarioConfig": {
      "id": "punjab-fog-pincer-01",
      "name": "Punjab Border — Zero Visibility Pincer",
      "nameHindi": "पंजाब सीमा — शून्य दृश्यता पिंसर",
      "region": "PUNJAB_RIVERINE",
      "weatherPreset": { "visibility": 15.0, "windSpeedKmh": 12.0, "windBearingDeg": 270.0, "temperature": 4.0, "isNight": true },
      "swarmProfile": { "agentCount": 6, "decoyCount": 2, "attackerCount": 4, "tacticTree": "PINCER_LOW_FAST", "speedKmh": 120.0, "altitudeM": 8.0, "rfFreqGHz": [5.825, 2.4], "rfPowerDbm": 23.0 },
      "durationMaxSecs": 120,
      "seed": 42819,
      "version": 1
    }
  }
}
```

**Consumer reactions:**
- `swarm-ai`: initialise Boids system with `seed` + `swarmProfile`; spawn agents
- `aar-engine`: open NDJSON file at `sessions/<sessionId>.ndjson`; set `t=0`
- `ui-ux`: hide lobby screen; show Sensor Suite panes; set threat state to GREEN

## SCENARIO_TICK

Fired by the simulation loop at 10 Hz (every 100 ms). This is the heartbeat of the entire sim.
`swarm-ai` runs its Boids step internally; the resulting `swarmSnapshot` is embedded here.

```
SCENARIO_TICK payload {
  sessionId:      string              // same as SCENARIO_START.sessionId
  t:              number              // scenario-elapsed ms from startedAtMs, e.g. 12300
  swarmSnapshot:  SwarmAgentState[]   // full per-agent state — see SCHEMA.md Entity 2
  sensorReadings: SensorReadings      // computed by swarm-ai from swarmSnapshot + physics models
  threatState:    string              // "GREEN" | "AMBER" | "RED"
  traineeAction:  TraineeAction       // last input state captured from Trainee Cockpit at this tick
  ewJammerState:  EWJammerState       // current EW jammer config
  friendlyVhfActive: boolean          // ROE deconfliction signal
}
```

**Types (see SCHEMA.md for full field lists):**
- `SwarmAgentState` — per-agent position, velocity, RF, acoustic, RCS, neutralised flag
- `SensorReadings` — RF waterfall peak, Doppler peak, acoustic SPL, radar count
- `TraineeAction` — antenna bearing/elevation, EW engaged, kinetic event if fired
- `EWJammerState` — engaged, bearing, elevation, band, friendly-blackout-risk flag

**Example (abbreviated):**
```json

  "v": 1,
  "ts": 1759600033300,
  "payload": {
    "sessionId": "sess-20261004-143201",
```

**Consumer reactions:**
- `swarm-ai`: advances internal HBT; computes next tick's sensor readings (fed back to next TICK)

- `ui-ux`: redraws RF Waterfall, Doppler scope, Acoustic FFT, threat-state indicator

**Performance note:** Payload is ≤ 8 KB for 6 agents. localhost loopback; no compression needed.

## SCENARIO_END

Fired when any terminal condition is met.

```
SCENARIO_END payload {
  sessionId:     string    // same as SCENARIO_START.sessionId
  t:             number    // scenario-elapsed ms at end
  reason:        string    // "TIME_LIMIT" | "ALL_NEUTRALISED" | "EXCLUSION_BREACH" | "INSTRUCTOR_ABORT"
  finalSwarmSnapshot: SwarmAgentState[]   // last known state of all agents
}
```

**Terminal conditions:**
| reason | trigger |
|---|---|
| `TIME_LIMIT` | `t >= durationMaxSecs * 1000` |
| `ALL_NEUTRALISED` | all `attackerCount` agents have `isNeutralised == true` |
| `EXCLUSION_BREACH` | any attacker agent enters inner exclusion zone (radius 20 m of origin) |
| `INSTRUCTOR_ABORT` | Instructor presses "Abort" in C2 UI |

**Example:**
```json
{
  "type": "SCENARIO_END",
  "v": 1,
  "ts": 1759600076000,
  "payload": {
    "sessionId": "sess-20261004-143201",
    "t": 55000,
    "reason": "ALL_NEUTRALISED",
    "finalSwarmSnapshot": [
      { "agentId": "agent-3", "isDecoy": false, "isNeutralised": true, "neutralisedAtMs": 45210, "positionWorld": {"x": 12.0, "y": 6.1, "z": -3.4}, "velocityMs": {"x":0,"y":0,"z":0}, "headingDeg": 247.0, "altitudeM": 6.1, "rfEmitting": false, "rfFreqGHz": 5.825, "rfPowerDbm": 0, "propellerRpm": 0, "rcs": 0.012 }
    ]
  }
}
```

**Consumer reactions:**
- `aar-engine`: flush final NDJSON line; compute Scorecard (≤ 10 s); emit `SCORECARD_PAYLOAD` via WS
- `ui-ux`: freeze sensor panes; show "Computing Scorecard…" overlay
- `swarm-ai`: halt HBT; free agent memory
